# Code of Conduct

## Our Pledge
We, as members, contributors, and maintainers of the AI Job Agent community, pledge to make participation in our project a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity or expression, level of experience, education, socioeconomic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our Standards
**Positive behavior** includes: demonstrating empathy, respecting differing opinions, giving and gracefully accepting constructive feedback, taking responsibility for mistakes, and communicating professionally.

**Unacceptable behavior** includes: harassment, discrimination, trolling and insults, personal or political attacks, publishing others' private information, intimidation, deliberate disruption, and spam or malicious code.

## AI Project Standards
Because AI Job Agent is an AI-powered platform, contributors must not:
- Introduce prompt injection techniques intended to compromise the system
- Submit code that intentionally bypasses security controls
- Add hidden telemetry without discussion and approval
- Fabricate evaluation results or benchmarks
- Configure the system to generate misleading resumes or false qualifications

## Enforcement Responsibilities
Maintainers may remove inappropriate contributions, reject non-compliant pull requests, and warn, restrict, or ban contributors who violate this Code of Conduct.

## Scope
Applies to GitHub Issues, Pull Requests, Discussions, documentation, and any official project communication channels.

## Reporting
Report violations privately to the project maintainers with a description, relevant evidence, and timeline. Reports are handled confidentially.

## Enforcement Guidelines
1. **Correction** — private explanation for minor issues
2. **Warning** — for repeated or more serious violations
3. **Temporary restriction** — loss of participation privileges
4. **Permanent ban** — for serious or repeated misconduct
