# Support

## Before Asking for Help
Check the [README](README.md), the [docs/](docs/) folder, and existing GitHub Issues — many questions may already be answered.

## Reporting Bugs
Open a GitHub Issue including OS, Python version, browser (if applicable), logs, error messages, and steps to reproduce.

## Feature Requests
Explain the problem you're solving, your proposed solution, alternatives considered, and expected benefit.

## Security Issues
Do not use public issues — follow [SECURITY.md](SECURITY.md).

## Response Priorities
1. Security issues
2. Critical bugs
3. Documentation errors
4. Feature requests
5. General questions

## Commercial Support
No SLA is currently offered. Enterprise support may be introduced as the project matures.
