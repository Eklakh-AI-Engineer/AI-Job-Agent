# Candidate knowledge base directory.
# YAML files defining skills, claims, experience, and preferences
# will be added here in a future phase.
#
# Expected structure (future):
#   candidate/
#   ├── profile.yaml          # Core identity and targets
#   ├── skills.yaml           # Skills with evidence references (SKILL-n)
#   ├── claims.yaml           # Verifiable claims (CLAIM-n) with disclosure levels
#   ├── experience.yaml       # Work and project history
#   └── preferences.yaml      # Role, location, compensation preferences
#
# Disclosure levels used in evaluation:
#   public      - safe to include in public-facing outputs (resumes, LinkedIn)
#   restricted  - usable as internal evaluation evidence ONLY; must not appear in
#                 any public-facing text or generated documents
#   undetermined - treat as restricted until explicitly reviewed
